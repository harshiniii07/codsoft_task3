# Customer Churn Prediction

This project is part of the CodSoft Machine Learning Internship.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

## Description
This machine learning project predicts whether a customer is likely to leave a subscription-based service using customer demographic and banking information.

## Features
- Data preprocessing and cleaning
- Label Encoding for categorical features
- Feature scaling using StandardScaler
- Multiple Machine Learning models:
  - Logistic Regression
  - Random Forest
  - Gradient Boosting
- Model evaluation using:
  - Accuracy Score
  - Classification Report
  - Confusion Matrix
- Best model comparison and selection
- Custom customer churn prediction

## Output
The system predicts whether a customer is likely to stay with the bank or leave the service based on customer details and usage behavior.
